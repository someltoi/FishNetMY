## Dataset Folders

### 1. COCO
This is specifically for **Faster** and **Mask R-CNN**

Each folder contains 4 different folders: 
- Train (Preprocessed and Augmented Images)
- Test (Preprocessed Images)
- Validation (Preprocessed Images)
- Labels inside **_annotations.coco.json** (Bounding box/Masking Coordinates)

### 2. YOLO
This is specifically for **YOLO** model

Each folder contains 4 different folders: 
- Train (Preprocessed and Augmented Images)
- Test (Preprocessed Images)
- Validation (Preprocessed Images)
- Labels (Bounding box/Masking Coordinates)
